# HayDev — research matrix

Date: 2026-09-13. Research performed before product-source authoring. Sources below were opened through web search. Text extraction is not a full live visual audit; JavaScript-only and unavailable sources are explicitly identified. Costs are qualitative design estimates, not measured source-site benchmarks. No source code, client logos, claims or brand assets are copied.

| Source / Module | Category | Strong Pattern | Weak Pattern | Adopt / Adapt / Reject | Reason | Cost | Risk | Implementation Note |

| [Lenis](https://lenis.dev/) | Smooth scroll | Continuous scroll presentation | Scroll ownership adds complexity, motion and accessibility risks | REJECT | Native navigation is sufficient | No dependency added | Library not used | Native anchor scrolling; reduced-motion disables smoothing |

Decision: original Orbital Control identity. Adopt product principles from five inspectable sites; keep two limited-evidence references documented. No imitation of a source's layout. Use original generated art, native CSS transitions, catalog Radix primitives, functional SVG process diagrams. No additional runtime dependencies. All visible interactions usable by touch and keyboard; animation is never the only carrier of information.
