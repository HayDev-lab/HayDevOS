# Монтажная и встроенный генератор

Маршрут: `/marketing/editor`. Кнопка «Բովանդակության գեներատոր» / «Генератор контента» открывает генератор внутри монтажной. Созданный файл можно просмотреть и добавить в проект: видео, изображение и аватар заменяют основной источник, музыка и голос добавляются на отдельные дорожки.

## Монтаж по промпту

Откройте «Монтаж по промпту», введите команду, проверьте предложенные изменения и нажмите «Применить». Последнее применение можно отменить. Например:

> Вертикальный 9:16, обрежь с 2 до 12 секунд, заголовок «Наш продукт», логотип справа сверху, добавь субтитры.

Явные команды для формата, обрезки, заголовка, черно-белого/сепия фильтра, позиции логотипа и транскрипции распознаются локально на русском, армянском и английском. Для других поддерживаемых настроек используется настроенный провайдер Owner AI. Редактор проверяет границы отрезка и допустимые значения перед применением. Команда субтитров запускает транскрипцию после применения; для нее нужен отдельный медиапровайдер.

Текущая модель проекта: один основной источник, музыкальная дорожка, голос и звуковая дорожка. Автоматическая нарезка нескольких исходников и переходы между ними не реализованы.

## Субтитры и транскрипция

В инструменте «Ենթագրեր» / «Субтитры» можно импортировать SRT/VTT, создать и редактировать реплики со временем начала и конца, перейти к реплике на таймлайне и скачать SRT/VTT. Экспорт субтитров обрезает реплики по выбранному отрезку и начинает их время с нуля. Постоянная подпись используется, когда реплик по времени нет.

Для автоматического распознавания выбираются основной видео/аудиофайл, музыка или голосовая дорожка и язык (автоматически, русский, английский, армянский). Если браузер декодирует звук, выбранный отрезок отправляется как моно WAV 16 кГц, а полученное время возвращается к шкале исходника. Если декодирование недоступно, отправляется исходный файл до 4 МиБ. Ответ без временных меток сохраняется только как текст: временные метки не выдумываются. Текст можно скачать в TXT.

## Логотип и экспорт

«Ապրանքանիշ» / «Бренд» принимает PNG, JPEG и WebP до 4 МиБ, в том числе прозрачный PNG. Доступны четыре угла, размер и прозрачность. Логотип виден в предпросмотре, включается в WebM и сохраняется в JSON проекта вместе с субтитрами и настройками. JSON содержит настройки и имена медиафайлов; импорта проекта с восстановлением исходников пока нет.

«Экспортировать монтаж · WebM» создает файл через Canvas, Web Audio и MediaRecorder, включая обрезку, трансформации, эффекты, текст, субтитры, логотип и аудиодорожки. Разрешения: 1280×720, 720×1280 или 960×960. Экспорт идет в реальном времени, вкладка должна оставаться открытой и активной. Требуется браузер с поддержкой этих API. «Скачать исходный файл» отдельно скачивает оригинал без обработки.

## Настройка провайдера

Ключи задаются только на сервере. См. `.env.example`:

- `STUDIO_AI_API_KEY` (или `OPENAI_API_KEY`), `STUDIO_AI_BASE_URL`: OpenAI-совместимый API для изображения/аватара, голоса и транскрипции. Стандартные модели: `gpt-image-1`, `gpt-4o-mini-tts`, `whisper-1`. Переопределения: `STUDIO_IMAGE_MODEL`, `STUDIO_VOICE_MODEL`, `STUDIO_TRANSCRIPTION_MODEL`.
- Аватар в этом адаптере — изображение по загруженной фотографии. Анимация аватара не реализована.
- `STUDIO_MEDIA_GATEWAY_URL`, `STUDIO_MEDIA_GATEWAY_KEY`, `STUDIO_MEDIA_GATEWAY_KINDS`: отдельный шлюз для видео, музыки и других типов. Поддерживаемые типы перечисляются через запятую: `video,audio,voice,image,avatar`. Шлюз имеет приоритет для перечисленных типов.
- `OWNER_AI_*` используется для интерпретации промптов монтажа; текстовый API не считается медиапровайдером.

Шлюз принимает POST multipart/form-data: `kind`, `prompt`, `aspectRatio`, `durationSec`, `voice`, необязательный бинарный `reference`. Заголовки: `Authorization: Bearer <server-key>`, `X-HayDev-Organization`, `X-HayDev-Actor`. Ответ — бинарный файл до 40 МиБ с соответствующим Content-Type (`video/*`, `audio/*`, `image/*`), без ссылки на скачивание. Перенаправления запрещены, в production требуется HTTPS.

Лимит загружаемого на сервер файла — 4 МиБ; оригинал для подготовки транскрипции в браузере — до 50 МиБ. Таймаут запроса к провайдеру — 110 секунд. Все серверные маршруты требуют существующую сессию организации и имеют ограничение частоты запросов. Без настроенного медиапровайдера облачная генерация и транскрипция недоступны; ручной монтаж, субтитры, логотип и браузерный экспорт остаются доступны.

Контракты адаптеров проверены локальными тестами. Реальные вызовы внешнего генератора и распознавания речи требуют отдельной проверки после подключения провайдера.
