   114→- Key design decisions:
   115→  1. **Auth state via `useSyncExternalStore`** (not useState+useEffect). The authed flag lives in module scope and is read from localStorage at client module-eval time. A `queueMicrotask` flips a `hydrated` flag after the first client render so `getSnapshot` returns `false` on both SSR and the client's first paint — no hydration mismatch, no setState-in-effect lint violation.
   116→  2. **Local command palette state** — the search `query` lives in CommandPalette, reset to "" on open via the `onOpenChange` event handler (not an effect). The store's `searchQuery` field remains available for future modules but isn't driven by the palette.

   118→  4. **Module health dots** on the dashboard are derived from the same mock data (SLA breaches → warn, failed automation runs → err, reauth_required integrations → warn/error) so the dashboard surface stays consistent with the underlying modules.
   119→  5. **OwnerAiPanel** is intentionally a locked placeholder (disabled input + "Coming soon" badge + example prompts behind a Lock icon) — Task 10 will replace the body with the real assistant.

   121→  7. **i18n everywhere**: every visible string flows through `t(key, locale)` from `useLocale()`. Switching language in TopBar, UserMenu, LoginScreen, or SettingsPanel updates the entire shell instantly (Zustand persist).
